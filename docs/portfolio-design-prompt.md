Create a high-fidelity desktop website mockup for the personal portfolio of **Niloy Chandra Datta**, a CSE student and future MSc/PhD researcher focused on AI/ML Systems, Distributed Systems, Machine Learning Systems, Java/Spring Boot backend engineering, and production software.

The website must feel like the personal site of a serious research engineer — not a student template, not a SaaS dashboard, not a gaming portfolio, and not a generic AI-generated developer website.

## Overall visual direction

Design language:

- Academic editorial design
- Research laboratory aesthetic
- Premium engineering portfolio
- Minimal but not empty
- High information quality
- Strong typography
- Evidence-first
- Technical and sophisticated
- Internationally professional
- Suitable for professors, PhD supervisors, AI/ML recruiters, backend recruiters, and software engineering hiring managers

Visual inspiration should feel like a blend of:

- a modern university research lab website
- a premium engineering publication
- a clean developer platform
- editorial technology journalism
- high-end product design

Do NOT copy any existing website.

## Avoid completely

Do not use:

- stock workspace photographs
- laptop-on-desk hero images
- 3D floating objects
- neon cyberpunk colors
- purple-blue gradient backgrounds
- excessive glassmorphism
- glowing cards
- large rounded SaaS cards everywhere
- particle backgrounds
- matrix effects
- animated code rain
- fake terminal windows
- typing-animation aesthetic
- gaming UI
- giant GitHub statistics
- contribution heatmaps
- trophy widgets
- skill progress bars
- “Python 95%”
- huge technology-logo walls
- excessive badges
- fake testimonials
- fake metrics
- fake awards
- generic “Hello, I am a developer” styling

The work itself should create the visual impact.

## Color system

Use a restrained neutral palette.

Light mode:

- warm off-white background
- near-black text
- subtle cool-gray borders
- deep cobalt or dark blue as the only primary accent

Example mood:

background: #FAFAF7  
primary text: #111318  
secondary text: #656A72  
border: #E7E7E3  
accent: deep cobalt blue

Do not use more than one strong accent color.

## Typography

Typography must be one of the strongest visual features.

Use:

- an elegant editorial serif or refined modern display font for major headings
- a clean sans-serif for body text
- subtle monospace for metadata, project numbers, experiment IDs, technologies, and section labels

Large type should create visual hierarchy instead of cards or illustrations.

Use generous whitespace.

## Page width and grid

- Desktop viewport around 1440px wide
- Content max-width approximately 1180–1240px
- 12-column editorial grid
- strong vertical rhythm
- thin separators
- asymmetrical layouts where appropriate
- spacious but information-dense
- no oversized empty hero taking the entire screen
